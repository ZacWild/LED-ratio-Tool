| 项 | 实现 | 位置 |

decideHeightTier(clientH, workH):
  if (workH > 0 && workH < 680 + 65) return 3   // 工作区放不下最小标准客户区 → 重量收纳
  if (clientH >= 784)                return 1   // ① 标准

#### 4.4.2 分档判定阈值（**按 `scaleFactor` 换算，不写死 712** —— TK-79）

> 🔴 实测依据：**总非客户区增量 = 65 DIP @100%**（39 + 26 原生菜单）；`getMinimumSize()` = 1040×745（外框口径）。
> 因此「客户区 680」所需的工作区高度 = `680 + 65×sf`。

```
clientH  = window.innerHeight                     // 客户区（DEC-14 口径）
workH    = window.screen.availHeight               // 工作区（== Electron screen.workArea.height）
minH     = 680                                     // DEC-07 最小标准客户区
needH    = minH + 65×sf                           // 撑住 680 客户区所需的工作区高度

if (workH < needH)      tier = 3   // 工作区放不下 → 重量收纳
else if (clientH >= 784) tier = 1  // 标准档
else if (clientH >= 680) tier = 2  // 紧凑高度（轻量收纳）
else                     tier = 3  // 极低高度（重量收纳）
```

| 阈值 | 含义 | @100% 实测工作区高度 |
|---|---|---|
| `workArea.height ≥ 745` | **第①档**：标准最小客户区 1024×680 **放得下** | ≥ 745 |
| `680 ≤ clientH < 784` | **第②档**：紧凑高度 → 轻量收纳 | 窗口总高 < 809 |
| `clientH < 680` | **第③档**：极低 → 重量收纳（舞台折叠） | 窗口总高 < 745 |

> ✅ **TC-H-01 实测判定序列** = `[1,1,2,2,3,3]`（输入 900/784/783/680/679 @workH=1392 + 900@workH=744）。

> ✅ **TC-H-03 实测**：1440×900 → standard；1440×750 → compact；1440×600 → tight；1440×900 → standard（**resize 动态重算**）。
